# Bee data sourcing result

October 20, 2026. Tony confirmed he has no real Bee data source and asked for an online open-source resource.

**No publicly downloadable, licensed dataset with verified Amazon Bee-device provenance was found in this search.** That is a search result, rather than a claim that none exists anywhere. The integration is ready; Bee-track evidence remains open.

| Resource checked | What it supplies | Qualifying data? |
|---|---|---|
| [Official developer docs](https://docs.bee.computer/) | Account login, CLI, real-time stream, local proxy and MCP instructions | Access to the authenticated owner's own data; no public dataset advertised |

| [BeeSense AI](https://github.com/nidhi-n-d-gowda/beesense-ai), [Busy-Bee](https://github.com/oliverncolon-cyber/Busy-Bee) | Public hackathon application code (MIT / Apache-2.0 respectively) | No verified licensed authentic recording corpus identified |

The [official event rules](https://amazonappdev2026.devpost.com/rules) require actual Bee-device or Bee-on-Apple-Watch data and a working data interaction in the video. Example JSON, other wearables' datasets and ordinary speech corpora cannot establish that provenance.
